# Security Policy

## Supported versions

Security fixes are provided for the latest released version of CopyCue.

## Reporting a vulnerability

Please do not disclose an unpatched vulnerability in a public issue. Use GitHub's **Security** tab and **Report a vulnerability** to open a private report. Include the affected version, reproduction steps, expected impact, and any suggested mitigation.

Do not include real passwords, tokens, private keys, or sensitive clipboard contents in a report. Use synthetic test data instead.

If private vulnerability reporting is not yet available for the repository, open a public issue requesting a private contact channel without including vulnerability details.
